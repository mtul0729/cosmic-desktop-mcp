# 适用范围与设计原则

[English](design.md) | **简体中文**

`cosmic-desktop-mcp` 是一个小型开源工具，通过 MCP 暴露一组聚焦的 COSMIC 桌面操作。它不是
平台，也不试图提供完整的桌面自动化栈。

## 适用范围

- 不依赖 X11 或 GNOME 专用工具，截取 COSMIC 输出和窗口。
- 读取窗口状态、位置和工作区归属。
- 通过 COSMIC 的 EIS 通路发送指针和键盘输入。
- 把坐标转换和 RemoteDesktop 授权流程集中在一份实现里，避免在脚本或每个 MCP 客户端中
  重复实现。

调用方通常已经能访问这台机器，例如通过 shell 或其他宿主工具。MCP 只是暴露这些桌面操作的
接口，不是 shell 替代品、沙箱或权限边界。

## 设计原则

### 1. 优先使用原生机制

使用 COSMIC 实际实现的协议和机制。不要为了让旧 Linux 配方继续工作而增加 X11、
`/dev/uinput`、GNOME Shell 或 `wlr-screencopy` 回退。协议发现和失败方案记录在
[工程笔记](engineering-notes.md)中，避免以后重复踩坑。

### 2. 暴露桌面语义，不包装 shell 命令

MCP 工具面用于 COSMIC 状态、几何信息、截屏和输入。普通命令不会仅仅因为可以包成 JSON 就
变成桌面能力。命令配方放在[操作 skill](../skill/cosmic-desktop-ops/SKILL.md)中。

### 3. 明确区分坐标空间

输出截图像素、窗口图片像素和逻辑桌面坐标属于不同空间。工具不能根据 `x`/`y` 推断输出；
窗口图片必须连同生成它时的完整 `coordinates` 对象一起传回。转换存在歧义时返回错误，
不要猜测。

### 4. 分开观察、准备和操作

观察类工具不能打开输入会话或弹出 portal 对话框。`prepare_input` 是显式的准备步骤。输入
工具可以惰性打开会话，但必须明确它们是操作，并返回足够的信息核对实际结果。

### 5. 不静默猜测

窗口选择器、工作区名称或输出匹配存在歧义时拒绝执行。过期的窗口坐标必须拒绝。授权被拒绝、
不可用或超时时返回结构化错误。向合成器发送请求不等于请求已经生效，调用方必须能够重新
读取结果状态。

### 6. 让副作用可见、可回滚

指针操作返回实际使用的输出、逻辑坐标、命中测试和锁屏状态。`config_write` 返回旧值；
`restart_applet` 恢复原始配置并保留备份；截图返回路径和尺寸。无法确认的操作应如实说明，
不能把请求当成确定成功。

### 7. 授权由人控制

输入经过 RemoteDesktop portal 和恢复令牌。锁屏行为会被报告，不会被绕过。服务不会伪造
授权或隐藏被暂停的截图。能访问这个服务就等于拥有桌面控制能力，它不是沙箱能力。

### 8. 保持工具面精简

每个 MCP 工具都会增加 schema、文档和维护成本。只有调用方不应自行重建、且需要 COSMIC
特有状态或语义的能力才应做成工具。操作顺序、陷阱和普通 shell 配方放在 skill 中。

`app_logs` 因此被移除。它只校验进程名，然后执行：

```bash
journalctl --user -b --no-pager -n <lines> -t <name>
```

操作 skill 现在直接给出这条配方。

### 9. 在真实 COSMIC 会话中验证

代码能编译不代表协议路径完成。截屏、混合缩放坐标、焦点、锁屏和 applet 重启都要在真实
会话中验证。记录可能被后续改动推翻的实测结果；用户可见的陷阱变化时同步更新 skill。

### 10. 优先小而正确

不要为了功能广度削弱核心保证。一个范围更小、失败模式清晰的实现，比一个会悄悄点错屏幕、
窗口或工作区的“功能更全”实现更可靠，也更容易维护。

## 新功能应该放在哪里

一个能力需要 COSMIC 协议状态、桌面几何信息、输入会话处理或其他 COSMIC 特有结构时，适合
做成 MCP 工具。

如果它只是把普通 shell 命令包成 JSON，就写进
[操作 skill](../skill/cosmic-desktop-ops/SKILL.md)。操作顺序和规避方法也放在那里；工具
描述只说明单个操作，不承载整套工作流。

## 非目标

- shell 或通用命令执行 API。
- 安全边界。能访问这个服务就等于拥有桌面控制能力。
- 通用 Linux 桌面自动化工具；实现只面向 COSMIC Wayland。
- 屏幕共享、远程登录或系统管理服务。
- 把所有可能有助于调试 COSMIC 的 shell 工具都包装一遍。
